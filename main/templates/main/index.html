Furniture Store

REST API мебельного магазина: каталог мебели, карточки товаров по ID и оформление заказов с подтверждением на почту.

Базовый адрес {{ request.scheme }}://{{ request.get_host }}

От каталога до заказа

Четыре запроса покрывают весь путь клиента — от просмотра мебели до истории его заказов.

  1. 1
    GET/furniture/

    Весь каталог мебели. Добавьте ?category=, чтобы отфильтровать по типу.

    GET /furniture/?category=chair
  2. 2
    GET/furniture/<id>/

    Карточка одного товара по идентификатору. Если товара нет — ответ 404.

    GET /furniture/1/
  3. 3
    POST/orders/

    Создаёт заказ по списку ID товаров. Сумма считается на сервере, клиенту уходит письмо с подтверждением.

    POST /orders/ { "email": "client@example.com", "goods": [1, 2] }
  4. 4
    GET/orders/?email=

    Список заказов клиента. Параметр email обязателен.

    GET /orders/?email=client@example.com
